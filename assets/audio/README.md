# KonyaGo Radyo — ses dosyaları

Buraya **telifsiz** veya **lisansını aldığın** mp3 dosyalarını koy.

Örnek:
- `konya-1.mp3`
- `konya-2.mp3`

Liste: `assets/data/radyo-playlist.json`

## Önemli
Ticari türkü / plak kayıtlarını izinsiz yükleme. Geleneksel ezgi için:
- kendi kaydın
- Creative Commons açık lisanslı kayıt
- kamu malı (public domain) kayıt
